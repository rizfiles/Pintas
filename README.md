# Pintas

A lightweight Android launcher that gathers links to Google services on a single screen.
Ideal for phones with limited storage and RAM—no need to install each app individually.

- Requires no permissions
- No ads, no trackers, and no separate login required
- Links open via Chrome Custom Tabs, so logins are handled by the browser
- The list of services is located in `app/src/main/assets/services.json`; additions can be easily made via pull request

## Building
1. Open this folder in Android Studio and wait for the Gradle sync to complete.
2. Run the app on an emulator or device (`Run > app`).
3. If `gradlew` is missing, run `gradle wrapper` or generate it via Android Studio.
